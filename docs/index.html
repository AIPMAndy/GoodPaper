写论文，别把时间都浪费在 Word 格式上。GoodPaper 帮你检查模板段落样式，做基础自动排版，导出批量诊断报告。开源、免费、可以自己部署。

3 分钟本地启动 ↗查看源代码 ↗

目前仅支持本机部署处理 DOCX。本页是静态介绍，不提供在线上传或云端排版；复杂格式请人工复核。

先把最重复的工作交给程序。

能力说明遵循实际源码边界，不会用“论文全自动合规”误导用户。

01 / CHECK

格式检查

基于模板检查常用段落样式、标题、摘要、部分题注和引用编号。

02 / FORMAT

基础排版

输出新的 DOCX 文件。保留原稿，修改后仍需在 Word/WPS 人工验收。

03 / REPORT

批量报告

批量处理本地 Word 文档，生成可核对的 JSON / CSV 报告。

开发者可以直接部署。

Python 3.10—3.12；本机启动后打开 http://127.0.0.1:8787。默认没有公网服务和用户账户。

git clone https://github.com/AIPMAndy/GoodPaper.git cd GoodPaper python -m venv .venv source .venv/bin/activate python -m pip install -r requirements.txt python app.py serve

Windows PowerShell 使用 .venv\Scripts\Activate.ps1；请不要把本地服务直接暴露到公网，机密论文不应上传到未授权平台。
