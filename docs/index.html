YOUR WORKFLOW

整个流程，三步就够。

最关键的是使用真实的学校或期刊模板，再对排版后的文件做最终人工验收。

01

选择模板

优先选用你有权使用的学校/期刊官方 DOCX 模板。仓库自带模板只用于技术演示。

02

上传检查

在本机网页里检查论文，查看样式差异和部分引用编号问题，先弄清楚哪里需要改。

03

导出与复核

必要时输出新 DOCX，然后在 Word/WPS 对页边距、图表、目录、参考文献等逐页比对。

RUN LOCALLY

自己部署。
不用把论文交给陌生网站。

只需要 Python 3.10–3.12、Git 和一个终端。项目默认仅监听 127.0.0.1:8787，处理过程在自己的计算机上完成。

复制命令就能启动。

先安装 Python、Git，再选对应操作系统执行右侧命令。浏览器打开 http://127.0.0.1:8787 使用真实检查和排版工具。

SCOPE & SAFETY

已实现的功能要讲清楚，没做好的也一样。

  • 已支持：DOCX、部分段落样式/题注检测、有限引用编号检测、模板驱动的基础排版、批量报告。

FAQ

常见问题。

能直接在这个网页上传论文吗？

不能。这里是 GitHub Pages 静态介绍页，不处理或接收论文。请按照上面的步骤在自己的电脑上运行 GoodPaper，再访问本机地址。

是不是所有学校的模板都能一键套用？

不是。不同 Word 模板的结构、样式 ID 和规范可能不同。现阶段主要是启发式检查与部分段落样式映射，需要用自己的真实模板做兼容测试。

支持 PDF 或完整的 GB/T 7714 参考文献规范吗？

当前主要面向 DOCX，暂不承诺 PDF 处理或完整 GB/T 7714 合规。仅具备有限的参考文献编号与引用一致性检查。

排版会覆盖我的原稿吗？

命令行默认输出新的文件，并拒绝把输出路径设置成输入文稿的同一路径。请仍然保留独立备份，并逐页检查复杂编号、公式和目录等内容。

项目免费吗？需要邀请码吗？

开源模式默认可以直接使用，无需购买邀请码。仓库中的可选激活机制面向开发者私有分发，使用免费开源版不需要配置。

我发现错误，应该怎么反馈？

欢迎在 GitHub 提交 Issue，附上脱敏复现步骤。请不要上传含有个人信息、尚未公开的研究数据或机密论文的原始文件。
